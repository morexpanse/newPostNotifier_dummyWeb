💡 cachi app & cachi server 테스트 절차

1
서브 URL 복사
구독하고 싶은 게시판의 [📋 URL 복사] 버튼을 눌러 링크를 복사합니다.
2
cachi app에 등록
cachi app에서 [+ 새 알림 추가]를 눌러 주소를 등록하고 모니터링을 시작합니다.
3
새 글 발생 트리거
게시판 상단의 [⚡ 새 글 발생 시뮬레이션] 버튼을 눌러 신규 글을 노출시킵니다.
4
푸시 알림 수신
cachi server가 감지하여 스마트폰으로 전송된 알림을 탭해 상세 글로 이동합니다.
